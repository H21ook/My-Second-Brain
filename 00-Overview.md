# AI Second Brain Constitution

## Purpose

This Constitution defines the fundamental rules, principles, and workflows that govern this AI Second Brain.

Its purpose is to ensure that all knowledge remains:

- Consistent
    
- Reusable
    
- Maintainable
    
- AI-friendly
    
- Valuable over the long term
    

Every human contributor and every AI assistant working within this knowledge base should follow these documents.

---

# Constitution Documents

The Constitution consists of five core documents.

## 1. Knowledge Philosophy

**Purpose**

Defines why knowledge is collected and what the ultimate goals of this Second Brain are.

Read this document to understand the mindset behind the system.

---

## 2. Knowledge Principles

**Purpose**

Defines the rules that every knowledge note should follow.

These principles ensure that knowledge is written consistently and remains useful over time.

---

## 3. Knowledge Lifecycle

**Purpose**

Defines how knowledge evolves from raw information into permanent reusable knowledge.

Every note should move through this lifecycle before becoming part of the permanent knowledge base.

---

## 4. Note Types

**Purpose**

Defines the different kinds of notes that exist within this Second Brain.

Every note should belong to one primary type.

---

## 5. Knowledge Quality Checklist

**Purpose**

Defines the quality standards for permanent knowledge.

Every important knowledge note should be reviewed using this checklist before it becomes part of the long-term knowledge base.

# Knowledge Workflow

Every piece of knowledge should follow the same workflow.

```text
Capture
    ↓
Evaluate
    ↓
Distill
    ↓
Choose Note Type
    ↓
Write the Note
    ↓
Review Using Quality Checklist
    ↓
Store
    ↓
Improve Continuously
```

---

# Guiding Principles

This Second Brain is designed to:

- Build knowledge instead of collecting information.
    
- Optimize long-term learning instead of short-term memory.
    
- Reduce repeated research.
    
- Improve AI collaboration.
    
- Minimize unnecessary token usage.
    
- Capture decisions instead of conversations.
    
- Continuously refine knowledge over time.
    

---

# For AI Assistants

When contributing to this knowledge base, AI should:

- Follow the Knowledge Principles.
    
- Respect the Knowledge Lifecycle.
    
- Select the correct Note Type.
    
- Validate important notes using the Knowledge Quality Checklist.
    
- Prefer reusable, evergreen knowledge over temporary information.
    
- Improve existing knowledge instead of creating unnecessary duplicates.
    

AI should always prioritize quality, clarity, and long-term maintainability.

---

# Long-Term Vision

This Second Brain is not intended to become a collection of notes.

It is intended to become a continuously evolving knowledge system that improves decision making, software development, learning, and AI collaboration over many years.

Every knowledge note should increase the overall value of the system.

Knowledge is an asset.

The goal is not to write more notes.

The goal is to build a better thinking system.
